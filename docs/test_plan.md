## 1. Объект тестирования

**Сервис:** Google Maps Places API (учебный стенд Rahul Shetty Academy)  
**Base URL:** `https://rahulshettyacademy.com`  
**Авторизация:** query-параметр `?key=qaclick123`

| Метод | Endpoint | Описание |
|---|---|---|
| `POST` | `/maps/api/place/add/json` | Создание новой локации |
| `GET` | `/maps/api/place/get/json?place_id={id}` | Получение данных локации |
| `PUT` | `/maps/api/place/update/json` | Обновление адреса локации |
| `DELETE` | `/maps/api/place/delete/json` | Удаление локации |

---

## 2. Цели тестирования

- Проверить корректность CRUD-операций для ресурса Place
- Убедиться в правильности HTTP-статус кодов ответов (`200`, `404`)
- Проверить структуру JSON-ответов — наличие обязательных полей
- Проверить корректность значений полей в ответах
- Убедиться, что адрес обновляется после `PUT` (подтвердить повторным `GET`)
- Убедиться, что удалённая локация недоступна — возвращает `404`

---

## 3. Тестовые данные

### POST — тело запроса (создание локации)

```json
{
  "location": {
    "lat": -38.383494,
    "lng": 33.427362
  },
  "accuracy": 50,
  "name": "Frontline house",
  "phone_number": "(+91) 983 893 3937",
  "address": "29, side layout, cohen 09",
  "types": ["shoe park", "shop"],
  "website": "http://google.com",
  "language": "French-IN"
}
```

### PUT — тело запроса (обновление адреса)

```json
{
  "place_id": "<id из POST-ответа>",
  "address": "100 Lenina street, RU",
  "key": "qaclick123"
}
```

### DELETE — тело запроса (удаление)

```json
{
  "place_id": "<id из POST-ответа>"
}
```

## 4. Стратегия тестирования

**Тип:** Функциональное, интеграционное  
**Метод:** Автоматизированное — PyTest + Allure  
**Подход:** End-to-end CRUD-цикл в одном тест-кейсе. `place_id` из POST-ответа передаётся в GET, PUT и DELETE.

### Архитектура проекта

| Модуль | Файл | Описание |
|---|---|---|
| Тест-кейс | `test/test_app.py` | Оркестрирует шаги CRUD-цикла |
| API-клиент | `utils/api.py` | `Google_maps_api` — инкапсулирует HTTP-вызовы |
| HTTP-обёртка | `utils/http_methods.py` | `Http_methods` — обёртка над `requests` |
| Проверки | `utils/cheking.py` | `Cheking` — методы валидации ответов |

---

## 5. Scope

### ✅ В scope

- `POST` — создание локации с полным набором полей
- `GET` — получение созданной локации по `place_id`
- `PUT` — обновление адреса существующей локации
- `GET` — проверка обновлённых данных
- `DELETE` — удаление локации
- `GET` — проверка недоступности удалённой локации (`404`)

### ❌ Вне scope

- Негативные сценарии (пустой body, невалидный `place_id`, неверный API-ключ)
- Нагрузочное и security-тестирование
- UI-тестирование
